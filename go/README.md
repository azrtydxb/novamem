# novamem-server (Go)

The Go port of `packages/server`. Same env-var contract, same HTTP
surface, same Postgres schema — see
[the migration spec](../docs/superpowers/specs/2026-08-13-go-migration-design.md)
and [the parity audit](../docs/architecture/go-parity-audit.md).

## Building

```sh
go build ./cmd/novamem-server        # needs the embedded assets present
```

One build artifact is **checked in** because `go:embed` cannot reach
outside the module directory:

| Path                         | Source                   | Regenerated by               |
| ---------------------------- | ------------------------ | ---------------------------- |
| `internal/httpapi/admin-ui/` | `packages/admin-ui/dist` | `./scripts/sync-admin-ui.sh` |

The OpenAPI document is no longer an embedded copy of a TypeScript
artefact: `internal/httpapi/openapi.go` _is_ the source, and
`cmd/gen-openapi` writes `docs/api/openapi.json` from it. A CI drift
gate re-runs the generator and fails on a dirty tree.

### Admin dashboard

The dashboard SPA is served from the binary under `/admin/*`. After any
change to `packages/admin-ui`:

```sh
pnpm --filter @azrtydxb/novamem-admin-ui build
go/scripts/sync-admin-ui.sh
```

The sync drops `*.woff` (every face also ships as `woff2`, which every
browser since ~2016 prefers), taking the committed copy from 2.1 MB /
108 files to 1.3 MB / 65 files. `go/Dockerfile` runs both steps, so a
container build never depends on the committed copy being fresh.

`NOVAMEM_ADMIN_DASHBOARD=0` registers no `/admin` routes at all, exactly
as in the TS server.

## Deliberate divergences from `packages/server`

Everything else is transcribed behaviour; these are the choices worth
knowing about.

- **Rate limiting** (`NOVAMEM_RATE_LIMIT_PER_MINUTE`, default 600) runs
  _before_ auth, so unauthenticated traffic is counted too — in the TS
  server the auth hook 401s ahead of the limiter, which leaves exactly
  the traffic a limiter is for uncounted. Keys are X-Forwarded-For aware
  (TS keys on the socket address, which puts every caller behind an
  ingress in one bucket). Counters are in-memory and per-replica, like
  `@fastify/rate-limit`'s default store and like the existing quota
  limiter: N replicas means an effective ceiling of N × max.
- **All 25 allow-listed `/api/auth/*` routes are served natively** —
  sessions, JWT/JWKS, change-password and the full admin plugin
  (create/update/set-role/set-user-password/remove, ban/unban,
  list-user-sessions, revoke-user-session(s), impersonate and
  stop-impersonating). Routes the TypeScript server deliberately does
  not mount answer identically, `sign-up/email`'s 404 included.
  Origin/CSRF follows Better Auth: the check runs only when the request
  carries a `Cookie` header.
- **204 preflight responses carry no `Content-Length: 0`** — net/http
  suppresses it on 204 by design.
- Static assets are served with Go's `text/javascript` rather than
  `@fastify/static`'s `application/javascript`; both are correct.
- **`NOVAMEM_COLD_API_KEY`** has no counterpart in `config.ts` — the TS
  Qdrant client is constructed without one. Left unset (the only TS
  behaviour) the Go store sends no `api-key` header either; set, it adds
  the header so a secured Qdrant is reachable without a proxy.

## Env-var aliases

`NOVAMEM_DECAY_DAYS` is the canonical name for the decay half-life
(`config.ts` → `decay.defaultEffectiveDays`, default `7`). An early Go
build read `NOVAMEM_DECAY_DEFAULT_EFFECTIVE_DAYS` instead; that spelling
is kept as a **deprecated alias** so those deployments keep booting.
When both are set, `NOVAMEM_DECAY_DAYS` wins.

## Cold tier

Both providers from the TS server are implemented:

| `NOVAMEM_COLD_PROVIDER` | Backend                                           | `NOVAMEM_COLD_URL` default |
| ----------------------- | ------------------------------------------------- | -------------------------- |
| `pgvector`              | `memory_vectors` in Postgres                      | the warm database          |
| `qdrant`                | Qdrant REST API (no SDK dependency)               | `http://localhost:6333`    |
| unset                   | defaults to `qdrant`, exactly as `config.ts` does | `http://localhost:6333`    |

`NOVAMEM_PG_POOL_MAX` (default `20`) bounds the **warm** pool only; the
pgvector cold pool is fixed at 10 connections, matching
`cold-store-pgvector.ts`.
