# novamem documentation

The pages in this directory are the documentation source. They are also
what the published site is built from — [azrtydxb.github.io/novamem/docs](https://azrtydxb.github.io/novamem/docs/) —
so an edit here is an edit to the site.

Start at [index.md](index.md), or on the site, which has the navigation,
search and rendered diagrams.

`packages/docs-site/` holds only the VitePress configuration and static
assets now; there is no second copy of any page. See
[contribute/layout.md](contribute/layout.md) for the rest of the tree.
